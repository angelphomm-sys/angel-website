# Post template

1. Copy `post-template.mdx` into `content/posts/` and rename it to the post's web address, e.g. `my-new-post.mdx` (lowercase, hyphens).
2. Replace every [bracket]. Keep `draft: true` until it is ready; drafts never show on the live site.
3. Drop the Canva cover (2400x1350 PNG named `<post-slug>.png`) into `covers-inbox/` and run `npm run covers`.
4. Flip to `draft: false` and publish.
Rules: BLOG_REWRITE_GUIDE.md (voice, sources, no em dashes, share what worked for you).
